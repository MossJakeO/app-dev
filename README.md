## ✍️ Text Formatting

| Style | Syntax | Example |
|------|--------|--------|
| Italic | `*text*` or `_text_` | *Interstellar* |
| Bold | `**text**` | **The Dark Knight** |
| Bold + Italic | `***text***` | ***The Matrix*** |
| Strikethrough | `~~text~~` | ~~Old Movie~~ |

## 📝 Headings

```markdown
# Movie Title
## Genre
### Description
```

### Example:
# Inception  
## Sci-Fi / Thriller  
### A mind-bending film about dreams within dreams.
